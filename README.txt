EVERGLOW SMP — WEBSITE README

One World, One Community, One EverGlow.

1. TENTANG WEBSITE

Website EverGlow SMP merupakan website statis yang menyediakan informasi mengenai server Minecraft EverGlow SMP.

Website ini dibuat menggunakan:

- HTML
- CSS
- JavaScript
- Tanpa backend atau database
- Tanpa proses build atau instalasi package

7. MENJALANKAN WEBSITE

Website merupakan website statis sehingga dapat dijalankan tanpa backend.

Cara menjalankan:

1. Simpan file website dalam format ".html".
2. Buka menggunakan browser.
3. Website dapat langsung ditampilkan.

Untuk publikasi, website dapat diunggah ke layanan hosting statis seperti Netlify.

8. PENGELOLAAN WEBSITE

Informasi yang dapat diperbarui:

- IP Java dan Bedrock.
- Port server.
- Link Discord dan komunitas.
- Daftar command.
- Informasi fitur server.
- Daftar rank.
- Informasi ekonomi.
- Reward dan event.

Setelah melakukan perubahan, pastikan seluruh tab, tombol, pencarian, filter, dan tautan telah diuji kembali.

9. BATASAN WEBSITE

- Tidak menggunakan backend atau database.
- Tidak menampilkan status online server secara real-time.
- Tidak menampilkan jumlah pemain secara langsung.
- Tidak memproses login akun Minecraft.
- Tidak menyimpan password pemain.
- Informasi command bergantung pada konfigurasi server.
- Deep link Minecraft Bedrock dapat bergantung pada perangkat dan browser.

10. KEAMANAN

Demi menjaga keamanan akun dan komunitas:

- Jangan membagikan password kepada siapa pun.
- Jangan membagikan informasi pribadi.
- Pastikan tautan yang dibagikan berasal dari sumber resmi.
- Hubungi staff melalui Discord resmi apabila membutuhkan bantuan.

11. PEMELIHARAAN

Setiap kali server mengalami perubahan konfigurasi:

1. Periksa command yang masih aktif.
2. Perbarui informasi fitur.
3. Perbarui daftar rank dan benefit.
4. Periksa tautan komunitas.
5. Uji kembali seluruh fungsi website.
6. Simpan salinan cadangan sebelum memperbarui website.
