# EverGlow SMP Website

Website statis satu halaman untuk EverGlow SMP.

## Cara upload
1. Ekstrak `EverGlow_SMP_Website.zip`.
2. Upload file `index.html` ke root/publikasi website (misalnya Netlify Drop).
3. Pastikan file bernama `index.html`.

## Catatan
- Tidak membutuhkan backend, database, atau build step.
- Tombol salin memakai Clipboard API dengan fallback.
- Tab, pencarian, filter kategori, menu mobile, toast, dan Back to Top sudah aktif.
- Tombol Join Bedrock memakai deep link yang diminta; dukungan bergantung pada perangkat/browser.
- Website tidak menampilkan status online atau jumlah pemain karena belum ada integrasi API.
